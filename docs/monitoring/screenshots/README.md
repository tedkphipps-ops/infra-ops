# Monitoring Screenshots

This directory contains dashboard screenshots and visual monitoring references for the infra-ops homelab environment.

## Contents

### uptime-kuma-status-page.png

Infrastructure status page overview showing service availability across monitored hosts, DNS services, monitoring services, and storage resources.

### hub-pihole-dashboard.png

Pi-hole dashboard running on infra-hub, displaying DNS query activity, client statistics, and filtering metrics.

### rn-pihole-dashboard.png

Pi-hole dashboard running on redundant-net, providing DNS redundancy and failover monitoring visibility.

### hub-glances-dashboard.png

Glances system monitoring dashboard for infra-hub, displaying CPU, memory, disk, network, and process utilization.

### rn-glances-dashboard.png

Glances system monitoring dashboard for redundant-net, displaying system health, resource utilization, and service activity.

### infra-hub-grafana-dashboard.png

Grafana monitoring dashboard for infra-hub displaying system temperature, CPU usage, memory usage, root disk utilization, uptime, system load, Pi-hole DNS activity, Docker container logs, network traffic, NAS utilization, NAS service status, drive health, and NAS drive temperature.

### rn-grafana-dashboard.png

Grafana monitoring dashboard for redundant-net displaying system temperature, CPU usage, memory usage, root disk utilization, uptime, system load, Pi-hole DNS activity, Docker container logs, network traffic, backup NAS utilization, backup NAS service status, drive health, and backup NAS drive temperature.

## Notes

Screenshots are updated as infrastructure services evolve and major dashboard changes occur.

Monitoring screenshots serve as visual references for operational documentation and infrastructure validation throughout the repository.
